# Provenance of L1/S3 media

No generated imagery is used in these folders. The files are crops of figures
from primary NASA publications and retain the original figure captions where
the slide composition allows it.

## EPAD EMA flight test

Source: Stephen C. Jensen et al., *Flight Test Experience With an
Electromechanical Actuator on the F-18 Systems Research Aircraft*, NASA,
2000. The NTRS record marks the report as a work of the U.S. Government with
public use permitted.

Original:
https://ntrs.nasa.gov/api/citations/20010039533/downloads/20010039533.pdf
