# Протокол закрытого теста

Закрытый тест организуется преподавателем и не входит в студенческий
starter-репозиторий. Процедура проверяет независимость результата, а не пытается
криптографически скрыть общедоступный исходный датасет.

## Подготовка до S4

1. Из UCI Hydraulic Systems создаются train, validation, Test-A и Test-B по
   `split-v1` из [`_approved-datasets.md`](_approved-datasets.md).
2. Train и validation публикуются с метками. Test-A/Test-B получают случайные
   идентификаторы; таблица соответствия и метки хранятся только у преподавателя.
3. Публикуются хеш исходного архива, версия скрипта подготовки, размеры частей и
   хеш манифеста разбиения. Секретные идентификаторы в манифест не входят.
4. Test-A и Test-B не пересекаются с открытыми частями по
   `condition_block_id`. Набор содержит один стенд, поэтому перенос на новый
   физический объект не заявляется.

## Интерфейс сдаваемого пакета

Команда передаёт архив с:

```text
submission/
├── model.onnx
├── preprocessing.json
├── decision.json
├── predict                 # Linux CLI либо predict.py
└── submission.json         # версия данных, коммит и команды
```

Команда `predict <input-dir> <output.csv>` не обучает модель и не обращается к
сети. Выход содержит только `sample_id` и score/прогноз требуемой формы.

## Контрольные точки

- **S8 · проверка интерфейса.** Instructor-gate запускает пакет на технических
  примерах без тестовых меток. Команда получает ошибки схемы и формата.
- **S12 · Test-A, одна содержательная попытка.** Возвращаются только основная
  метрика, ограничения и статус «пройдено/не пройдено». Идентификаторы ошибок не
  выдаются. После этого Test-A больше не считается финальным.
- **S14 · Test-B, финальная попытка.** Оценивается замороженный кандидат. После
  получения метрик менять признаки, веса, порог и preprocessing нельзя.
- **S15 · итоговая демонстрация.** Повторно запускается пакет с тем же SHA-256. Новый тестовый
  просмотр не создаётся.

Технический сбой gate допускает одну повторную отправку в течение 24 часов,
только если SHA-256 `model.onnx`, `preprocessing.json` и `decision.json` не
изменились. Все попытки записываются в `gate-log.csv` преподавателя.

## Общедоступные исходные данные

Исходный UCI-архив общедоступен, поэтому закрытый тест является процедурным, а
не криптографическим. До S12 принимается SHA-256 кода и модели; одна попытка
Test-A возвращает только сводные метрики. Test-B запускается один раз для
замороженного кандидата S14. История коммитов должна показывать, что метки
закрытых частей не использовались для настройки. На S15 воспроизводится тот же
пакет и объясняется история решений.
