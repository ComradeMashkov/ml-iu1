# Русские тексты людей и нейросетей для S9

Источник: [CoAT, Corpus of Artificial Texts](https://huggingface.co/datasets/RussianNLP/coat), Shamardina и соавторы, 2025. Лицензия Apache 2.0.

Тексты людей взяты из корпуса русского языка, соцсетей, Википедии, новостей и личных дневников. Искусственные тексты созданы 13 нейросетями, например ruGPT3 и mT5. Это модели до ChatGPT, поэтому числа S9 описывают этот набор и не оценивают современные детекторы.

Отбор зафиксирован заранее: тексты длиной 25-70 слов; из текстов убрана разметка корпуса и HTML-сущности, иначе детектор учил бы разметку; исключены мат, актуальная политика и тяжёлые темы. У опубликованной части test нет меток, поэтому наши validation и test взяты из размеченной официальной части validation.

| Столбец | Смысл |
|---|---|
| `split` | train (6000), validation (2000), test (2000), в каждой половина от нейросетей |
| `ai` | 1: нейросеть, 0: человек |
| `word_length` | Средняя длина слова |
| `unique_share` | Разных слов / всех слов |
| `personal_per_100` | Слов я, мы, мне и подобных на 100 слов |
| `commas_per_100` | Запятых на 100 слов |
| `text` | Текст |
