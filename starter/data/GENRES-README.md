# Песни российских исполнителей для S10

Источник: [Spotify Dataset 1921-2020, 600k+ Tracks](https://www.kaggle.com/datasets/yamaerenay/spotify-dataset-19212020-600k-tracks), Yamac Eren Ay. Числа о звуке получены через Spotify Web API. Условия использования указаны на странице набора.

Выбраны песни с 1985 года, у первого исполнителя которых Spotify указывает российский жанр. Жанр приписан по исполнителю: рэп (russian hip hop, trap, drill), иначе рок (russian rock, punk, alternative, metal, ska), иначе поп (russian pop, dance). Поэтому у всех песен исполнителя один жанр. Повторы по паре название и исполнитель удалены.

Части заданы исполнителями: один исполнитель лежит только в одной части. Шесть исполнителей опроса и ещё двое заранее отнесены к test, остальные распределены случайно. В части usa лежат по 30 самых популярных песен 10 американских рэперов; в обучении они не участвуют.

| Столбец | Смысл |
|---|---|
| `track`, `artist`, `year` | Название, исполнитель, год |
| `genre` | рэп, рок или поп |
| `split` | train (2627), validation (1526), test (1595), usa (286) |
| `popularity` | Популярность в Spotify на момент выгрузки |
| `danceability`, `energy`, `speechiness`, `acousticness`, `instrumentalness`, `valence` | Оценки Spotify от 0 до 1 |
| `loudness` | Громкость, дБ |
| `tempo` | Ударов в минуту |
| `minutes` | Длительность |
