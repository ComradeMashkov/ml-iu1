# Рисунки котов и чайников для S7

Источник: [The Quick, Draw! Dataset, Google Creative Lab](https://github.com/googlecreativelab/quickdraw-dataset).
Рисунки созданы участниками игры Google Quick, Draw! и опубликованы Google, Inc.
под [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
Лицензия разрешает распространение и преобразование с указанием источника.

Файл `quickdraw-cat-teapot.npz` - небольшой учебный фрагмент исходных bitmap:

- [cat.npy](https://storage.googleapis.com/quickdraw_dataset/full/numpy_bitmap/cat.npy), строки 0-599;
- [teapot.npy](https://storage.googleapis.com/quickdraw_dataset/full/numpy_bitmap/teapot.npy), строки 0-599;
- [rabbit.npy](https://storage.googleapis.com/quickdraw_dataset/full/numpy_bitmap/rabbit.npy), строка 0, только для отдельной демонстрации.

Нумерация строк начинается с нуля. В каждом из первых двух классов 600 рисунков,
всего 1200. Порядок: коты, затем чайники. Каждый рисунок имеет размер 28 × 28,
хранится как 784 интенсивности штриха от 0 до 255. Ноль означает отсутствие
штриха. На графиках интенсивности показаны тёмным на белом фоне.

При подготовке проверены пустые изображения и точные повторы пикселей,
в том числе между классами. В выбранном фрагменте их нет. Изображения
не дорисованы, метки не исправлены. Преобразование для распространения:
перепаковка выбранных строк в один сжатый архив, добавление меток и номеров
исходных строк. При обучении интенсивности делятся на 255.

Поля архива:

| Поле | Содержание |
|---|---|
| `images` | 1200 строк × 784 пикселя, `uint8` |
| `labels` | 1200 меток: 0 = кот, 1 = чайник |
| `source_indices` | Номер строки в исходном bitmap соответствующего класса |
| `rabbit` | Один отдельный рисунок кролика из 784 пикселей |

Метка сообщает, какое слово предложили нарисовать игроку. Она не гарантирует,
что любой наблюдатель узнает предмет. Это естественное ограничение данных.

S7 заранее фиксирует разбиение `test_size=1/3, random_state=7, stratify=labels`:
800 обучающих рисунков, по 400 каждого класса; 400 проверочных, по 200 класса.
Проверочные строки не участвуют в обучении. Разбиение выполнено по рисункам.
Идентификаторов авторов в этом bitmap-фрагменте нет, поэтому разделение
по разным художникам не гарантируется.

Кролик не входит ни в train, ни в test. Один рисунок нужен для наблюдения,
как модель с двумя возможными ответами обрабатывает вход другой категории.
Это не оценка качества распознавания всех кроликов.

Источник учебной идеи: [Google Quick, Draw!](https://quickdraw.withgoogle.com/).
Наш опыт использует небольшую полносвязную сеть на CPU, это самостоятельная
учебная реализация, не воспроизведение промышленной модели Google.
