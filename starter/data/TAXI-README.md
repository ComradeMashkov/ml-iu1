# Данные семинара 6: цена поездки

Это отдельный самостоятельный опыт. Таблица не зависит от заказов S5.
Все цены и поездки синтетические. Реальные сервисы и тарифы не измеряли.

**Задача:** при заказе поездки оценить оплаченную стоимость в рублях по
плановому расстоянию маршрута и известному флагу часа пик. В целевой сумме
учитываем только стоимость поездки, без чаевых и покупок пассажира.

| Столбец | Значение |
|---|---|
| trip_id | ID учебной поездки, не вход модели |
| split | train для T01-T48, test для T49-T64 |
| distance_km | Плановое расстояние при заказе, 0.5-12 км |
| peak | Час пик в момент заказа: 0 или 1 |
| cost_rub | Оплаченная стоимость завершённой поездки, руб |

Фактически пройденный маршрут после поездки заранее неизвестен. Не подменяем
им плановое расстояние. Цену из чека не добавляем к входным признакам.

## Воспроизводимость

Генератор: NumPy default_rng, seed 20261006. Для каждой из 64 строк выбираем
расстояние из 0.5,1,...,12, пик из 0/1 и целый шум из -40,...,40.
Цена округлена до рубля:

`160 + 48 * distance_km + 3 * distance_km ** 2 + 130 * peak + noise`.

Эта формула показывает неизвестные условия и изгиб. Она не является тарифом
реального такси. В отличие от маленького примера цены в L2 здесь есть шум,
разные условия и отдельные проверочные поездки.

До просмотра test заданы четыре варианта: среднее train, линия по расстоянию,
линейная модель по расстоянию и пику, линейная модель по расстоянию, x² и пику.
Все обучаются по 48 train-строкам. Метрики MAE и RMSE считаем на тех же 16 test.
Результат одного набора не доказывает универсального преимущества признаков.

Файлы: [64 поездки](taxi-trips-synthetic.csv),
[отдельный чек](taxi-extra-trip.csv).

Дополнительная завершённая поездка: 3 км, пик=0, чек 1800 руб. Это заранее
заданный опыт чувствительности. Добавляем её только к копии train, основная
таблица и test остаются прежними. Сравниваем старую и новую модель на одинаковых
49 train и неизменных 16 test. Не удаляем подтверждённый чек ради метрики.

В итоговой задаче новая поездка имеет признаки [5,25,1]. Получаем прогноз
цены, сравниваем с бюджетом 700 руб и сообщаем ограничения оценки.
