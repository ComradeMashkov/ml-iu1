# Исторические матчи CS:GO для S8

Задача: по информации, доступной до матча, оценить победу первой команды.
Затем отдельно проверить правило условных единичных ставок с историческими
десятичными коэффициентами. Это архив CS:GO 2016-2019 годов.

Источник: [публикация автора набора](https://tabacof.github.io/posts/csgo_betting_with_ml_part_2/csgo_betting_with_ml_part_2.html).
Опубликованные исходные файлы:

- [Статистика и результаты матчей, dataset.parquet](https://github.com/tabacof/tabacof.github.io/blob/master/posts/csgo_betting_with_ml_part_2/dataset.parquet).
- [Исторические записи цен, match_predictions_with_odds.parquet](https://github.com/tabacof/tabacof.github.io/blob/master/posts/csgo_betting_with_ml_part_2/match_predictions_with_odds.parquet).

В первом файле 30640 уникальных матчей; после исключения 465 строк с
исходом tie остаются 30175 однозначных результатов. Во втором файле
1114302 записи цен для 1725 матчей, источник цен в файле обозначен ggbet.
Для учебного опыта используются фактические исходы и цены, а входные признаки
пересчитаны из предыдущих исходов. Прогнозы автора не используются как входы.
Отдельная лицензия исходных таблиц в репозитории автора не указана;
здесь не заявляется новая лицензия на его первичные файлы.

## Учебный файл

[csgo-match-features.csv](csgo-match-features.csv) содержит 7843 строки.
Одна строка соответствует одной серии BO3, то есть игре до двух побед
по картам. Порядок первой и второй команды взят из источника: победителя
не переставляют на первое место.

| Столбец | Смысл |
|---|---|
| `match_id` | Числовая часть идентификатора HLTV в исходном файле |
| `match_start` | Начало матча по исходной таблице |
| `decision_at` | Время, к которому сформированы входные признаки |
| `team1`, `team2` | Команды в зафиксированном порядке |
| `wins1_last10`, `wins2_last10` | Число побед среди 10 допустимых предыдущих результатов каждой команды |
| `team1_won` | 1, если победила первая команда; 0, если вторая |
| `odds1`, `odds2` | Десятичные коэффициенты в выбранной исторической записи; пустая строка означает отсутствие цены |
| `split` | Заранее назначенная часть: train, validation или test |

## Как получены признаки

К моменту `decision_at` для каждой команды берутся десять последних
однозначных исходов из архива. Включаются только матчи, чьё начало
в источнике находится более чем за 24 часа до `decision_at`.
Этот дополнительный запас выбран, поскольку файл не содержит отдельного
времени завершения каждой серии. До включения строки проверяется наличие
всех десяти предыдущих результатов у обеих команд.

Предыдущая история включает разные форматы матчей, целевая строка всегда
BO3. Число побед находится от 0 до 10. Входы сети: эти два числа, делённые
на 10. Нормировка задана смыслом признака и не обучается на test.
Текущий исход не входит в собственную историю.

## Как выбрана цена

Для каждого матча берётся последняя запись из окна за 24-48 часов до старта.
Обе десятичные цены должны быть больше 1. Если времена совпадают, порядок
цен используется только как фиксированное разрешение совпадений.
Максимум цены по будущей истории не выбирается.

В строках с ценой `decision_at` совпадает с временем её записи. Без цены
это время задано как `match_start` минус 24 часа. Предыдущие признаки
в обоих случаях рассчитываются заново к соответствующему времени.
Даты оставлены в шкале исходных таблиц; самостоятельного подтверждения
часовых поясов и реального исполнения ставок источник не даёт.

## Хронология

| Часть | Условие | Строк |
|---|---|---:|
| Train | Старт до 2019-01-01 | 6218 |
| Validation | `decision_at` с 2019-01-02; старт до 2019-04-25 | 952 |
| Test | `decision_at` с 2019-04-25; старт до 2019-07-08 | 673 |

Пограничные строки, не удовлетворяющие условиям, не включаются.
Фактический последний train-старт: 2018-12-30 04:00:00.
Первый validation-прогноз: 2019-01-03 16:00:00.
У 164 из 673 test-матчей есть подходящая цена. Brier на всех 673 строках
и финансовый результат на части с ценами относятся к разным подсчётам.
Для сравнения модели с оценкой из цен обе метрики считаются на тех же
164 строках.

## Фиксированный опыт

Сеть 2 → 8 → 1, ReLU, BCEWithLogitsLoss, SGD с шагом 0.5, 500 полных шагов,
seed=8, один поток CPU. Веса обучаются только на train. Постоянный ориентир:
3360 побед первой команды среди 6218 train-матчей.

Условное финансовое правило задано до просмотра test: начальный итог 1000,
ставка 1, только первая команда и только при `p * odds1 - 1 > 0.05`.
Без цены ставка не рассматривается. При исходе y чистый результат
единичной ставки равен `odds1 * y - 1`. Реальные счета и операции не нужны.

В эталонном запуске: 402 правильных класса из 673, Brier сети около 0.239843.
Правило выбрало 63 ставки на 164 матчах с ценой; 26 выиграли, чистый
условный итог +0.58. Это результат одного короткого исторического опыта,
не оценка гарантированной будущей прибыли. Источник не содержит журнала
исполнения, отмен и лимитов.
