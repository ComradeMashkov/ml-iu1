# SMS Spam Collection для S4

Авторы: Tiago A. Almeida и José María Gómez Hidalgo. 2011.
[Карточка UCI](https://archive.ics.uci.edu/dataset/228/sms+spam+collection),
[DOI 10.24432/C5CC84](https://doi.org/10.24432/C5CC84).
Лицензия по карточке UCI: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Исходное описание авторов сохранено в `sms-original-readme.txt`.

`sms-spam.tsv` — неизменённый файл `SMSSpamCollection` из
[архива UCI](https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip),
скачанного 22 сентября 2026 года. SHA-256:

```text
7d039a24a6083ed9ef0f806ebad56bbb976e3aeb8de05669173bfdc4996c239d
```

В этой копии 5574 строки: 4827 `ham` и 747 `spam`. Первая табуляция
разделяет метку и текст. Код семинара удаляет повторы текста после приведения
к нижнему регистру и объединения пробельных символов. Остаётся 5159 текстов:
4517 обычных и 642 спам-сообщения. Совпадающих нормализованных текстов
с противоречивыми метками в этой копии нет; это проверяет тест данных.

Версия учебного протокола: `sms-count-v1`. Словарь заранее фиксирован:
`free`, `win`, `prize`. `count_words` считает вхождения целых слов после
`lower().split()` и удаления `.,!?;:` с краёв каждого слова.
Повторное вхождение увеличивает счётчик повторно. Правило не обучается
на корпусе, поэтому его применение до разбиения не использует статистику теста.

Разбиение: scikit-learn из `starter/uv.lock`, два вызова `train_test_split`,
`random_state=25`, стратификация по метке. Сначала 60% / 40%, затем
оставшиеся 40% пополам. Получаются 3095 / 1032 / 1032 сообщения.
Порог выбирается только по валидационной части из `[0.10, 0.25, 0.50, 0.75]`
по условной цене `5 * FP + FN`. При равенстве сохраняется первый порог.
Тест открывается после фиксации модели и порога.

Единица решения — сообщение. Удаление текстовых повторов устраняет одну
из причин зависимости. Сведения об отправителях и кампаниях отсутствуют,
близкие шаблоны могут сохраняться. Порядок строк не является временным.
По этому эксперименту нельзя оценить качество на новых кампаниях,
русскоязычных сообщениях или SMS сентября 2026 года.

Воспроизведение из папки `starter`:

```bash
uv sync --locked
uv run python lessons/s04.py
```

Сеть при запуске не нужна. Набор относится к историческому корпусу
англоязычных сообщений. Короткие русские пояснения в сценарии служат
переводом смысла и не подменяют входные данные модели.
