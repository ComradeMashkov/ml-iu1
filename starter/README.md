# Starter-проект S1–S3

Эта папка — исходная точка практикумов. Скопируйте её в отдельный каталог, создайте Git-
репозиторий и работайте в нём на S1–S3.

```bash
mkdir ml-sau-team
git archive HEAD:starter | tar -x -C ml-sau-team
cd ml-sau-team
git init
uv sync --locked
make check
```

`git archive` копирует только файлы курса и не переносит локальную `.venv`. Если материалы
получены не через Git, скопируйте папку файловым менеджером без каталога `.venv`.

Начальная проверка должна проходить. В `sensor.py` и `baseline.py` оставлены сигнатуры задач
следующих семинаров; тесты для них студенты добавляют на S2 и S3.

## Подготовка перед S1

Нужно уметь:

- перейти в каталог (`cd`), посмотреть файлы (`ls`) и выполнить команду;
- создать и сохранить текстовый файл в редакторе;
- прочитать форму NumPy-массива и выбрать строки булевой маской;
- выполнить `git status`, `git diff`, `git add` и `git commit`.

Мини-проверка NumPy:

```bash
uv run python -c "import numpy as np; x=np.arange(6).reshape(3, 2); print(x[x[:, 0] > 1])"
```

Если команда или результат непонятны, разберите их до S1 с преподавателем или напарником.

## Что меняется по семинарам

| Семинар | Работа |
|---|---|
| S1 | `quality.py`, тесты, ветка и CI |
| S2 | реализация `sensor.py`, тесты и JSON-отчёт |
| S3 | реализация `baseline.py`, манифест разбиения и метрики |

Генераторы в `sensor_source.py` и `course_case.py` создают разные синтетические наборы для
разных учебных целей. Они не являются реальными полётными данными.
