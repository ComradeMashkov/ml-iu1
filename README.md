Для работы с notebook откройте терминал в папке `starter`:

```bash
uv sync --locked
make notebook
```

Начальные notebook находятся в `starter/notebooks`, разобранные примеры —
в `starter/notebooks/solutions`. S2 доступен как дополнительный материал.
